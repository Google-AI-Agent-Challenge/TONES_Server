[Development Context]
- Core Web/API: Python + FastAPI + Pydantic (v2.6+)
- Async WAS: Uvicorn (standard)
- Data Layer: Supabase (RDBMS, supabase-py SDK) + Pinecone (Vector Database)
- AI & LLM Integration: Google Gemini API (text-embedding-004, gemini-2.0-flash / gemini-1.5-flash)
- DevOps/Infra: Docker + Railway (Dockerfile 제공)
- Quality/Stability: Sentry (에러 추적, sentry-sdk) + Pytest (테스트 프레임워크)
- Security & Auth: JWT (python-jose) + Password Hashing (passlib[bcrypt], bcrypt) + Pydantic (데이터 검증) + Bandit / GitHub Dependabot (보안 진단)
- CI/CD: GitHub Actions (main.yml)

[Analysis of Discrepancies (Planned vs. Actual)]
1. 실제 추가된 비즈니스 도메인 (Dashboard):
   - 기획 단계의 'backend_framework_decision_making.txt'에는 없었으나, 실제 구현에서는 대시보드 기능이 핵심으로 포함되었습니다. 이에 따라 `api/v1/endpoints/dashboard.py`, `schemas/dashboard.py`, `services/dashboard_service.py`가 추가되어 대시보드 메트릭 및 통계를 담당하고 있습니다.
2. 데이터베이스 스키마 및 초기화 관리:
   - 기획에서는 `models/` 폴더를 빈 상태로 두었으나, 실제 개발에서는 `app/models/schema.sql`을 작성하여 데이터베이스 스키마를 명시적으로 문서화했습니다.
   - 프로젝트 루트에 `supabase/` 디렉터리가 추가되어 데이터베이스 초기화를 위한 `products.sql`과 대량의 테스트용 데이터를 구축하기 위한 `seed.sql` 파일이 구현되었습니다.
3. AI 핵심 기술 스택 구체화:
   - 기획에서는 "Pinecone 검색 및 LLM 연동" 정도로 추상적으로 명시되어 있었으나, 실제 구현에서는 Google Gemini API가 적극적으로 차용되었습니다.
   - 텍스트 임베딩 모델로는 `text-embedding-004`를 활용하여 쿼리를 벡터화하고 이를 Pinecone에 검색을 수행합니다.
   - 답변 생성 모델로는 최신 `gemini-2.0-flash` 모델을 메인으로 사용하고, 해당 API에 문제가 있을 시 `gemini-1.5-flash` 모델로 자동 폴백하는 구조가 구현되어 있어 높은 안정성을 갖추고 있습니다.
4. 보안 패키지 및 인프라 구체화:
   - JWT 검증을 위해 `python-jose`, 비밀번호 보안 강화를 위해 `passlib[bcrypt]`/`bcrypt`가 도입되어 로그인 및 인가 처리가 실제 구현되었습니다.
   - GitHub Actions CI/CD 파일(`main.yml`)과 PR 템플릿(`pull_request_template.md`)이 갖춰져 실제 협업 체계가 구축되어 있습니다.
