[Development Context]
- Core Web/API: Python + FastAPI + Pydantic (기본 내장)
- Async WAS: Uvicorn
- Data Layer: Supabase (RDBMS) + Pinecone (Vector)
- DevOps/Infra: Docker + Railway
- Quality/Stability: Sentry (에러 추적) + Pytest (테스트)
- Security: Pydantic + Bandit + GitHub Dependabot
- CI/CD: GitHub Actions

[Layered Architecture]
my_fastapi_app/
│
├── app/                     # 애플리케이션 핵심 소스코드
│   ├── api/                 # API 엔드포인트 (라우터) 레이어
│   │   ├── v1/
│   │   │   ├── endpoints/
│   │   │   │   ├── auth.py
│   │   │   │   ├── users.py
│   │   │   │   └── ai_search.py
│   │   │   └── api.py       # v1 라우터들을 하나로 통합하는 파일
│   │   └── deps.py          # 공통 의존성 (Supabase 클라이언트, 인증 등)
│   │
│   ├── core/                # 프로젝트 전역 설정 및 보안
│   │   ├── config.py        # 내부 환경변수 관리 (pydantic-settings)
│   │   └── security.py      # JWT 토큰 발행, 비밀번호 암호화 등
│   │
│   ├── models/              # DB 테이블 및 엔티티 레이어 (필요 시)
│   │
│   ├── schemas/             # Pydantic 데이터 검증 레이어 (DTO)
│   │   ├── auth.py
│   │   ├── user.py
│   │   └── ai_search.py
│   │
│   ├── services/            # 비즈니스 로직 레이어 (핵심 기능 처리)
│   │   ├── user_service.py
│   │   └── ai_service.py    # Pinecone 검색 및 LLM 연동 로직
│   │
│   └── main.py              # FastAPI 앱 생성 및 초기화 (진입점)
│
├── tests/                   # Pytest 테스트 코드 폴더
│   ├── conftest.py          # 테스트 공통 설정 및 피스처(Fixture)
│   ├── test_auth.py
│   └── test_ai.py
│
├── .env                     # 환경 변수 파일 (Supabase URL, API KEY 등)
├── .gitignore
├── Dockerfile
├── README.md
└── requirements.txt
