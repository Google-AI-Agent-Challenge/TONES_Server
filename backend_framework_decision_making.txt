[Back-End Development Context]
- Core Web/Framework: Python 3.11+ + FastAPI 0.110.0+ (고성능 비동기 API 웹 프레임워크 설계)
- Language: Python Type Hints (안정적이고 견고한 정적 분석 기반 타이핑)
- Async WAS: Uvicorn standard 0.28.0+ (고성능 비동기 ASGI 서버 구동 및 실시간 이벤트 제어)
- Data Layer: 
   - Supabase Client SDK 2.3.0+ (PostgreSQL RDBMS 연동, 트랜잭션 및 안정적인 데이터 CRUD 처리)
   - Pinecone Client SDK 3.1.0+ (고성능 벡터 데이터베이스 연동, 대규모 의미론적 검색 수행)
- AI & Analytics:
   - Google Gemini Embedding API (text-embedding-004 모델 탑재로 768차원 의미 벡터 생성)
   - Google Gemini Generative API (gemini-2.0-flash 차세대 인공지능 모델 탑재 및 실시간 RAG 기반 답변 생성)
   - Graceful Fallback Engine (gemini-2.0-flash 실패 시 gemini-1.5-flash 폴백 및 API 장애 감지용 오프라인 폴백 내장)
- Security & Middleware:
   - python-jose 3.3.0+ (JWT 기반 무상태 토큰 인증 시스템 구현)
   - passlib + bcrypt 4.0.1+ (강력한 단방향 비밀번호 솔트 및 해시 암호화 적용)
   - Pydantic v2 (Pydantic Settings v2 포함으로 컴파일 수준 스키마 검증 및 주입 공격 차단)
- Quality & Test:
   - Pytest 8.0.0+ (단위/통합 테스트 자동화 스위트 구축)
   - HTTPX Client (API 통합 테스트용 비동기 비차단 HTTP 통신 지원)

[Architectural Decisions]
1. FastAPI + Uvicorn Async Architecture & Pydantic v2 Static Validation
   - 비동기 ASGI 웹 서버인 Uvicorn 위에서 FastAPI의 async/await 동시성 제어를 활용하여 극대화된 스루풋(Throughput)과 최저 대기시간(Latency)을 보장.
   - Pydantic v2 기반의 엄격한 데이터 유효성 검증 레이어를 구축하여 API 엔드포인트 도달 전에 비정상적인 데이터 주입을 원천 차단하고 구조화된 데이터 흐름(DTO 패턴) 강제.
2. AI-Driven Hybrid Search & Robust Fallback Architecture
   - Google Gemini text-embedding-004 모델을 활용하여 사용자 쿼리를 768차원의 고차원 의미 벡터로 실시간 인코딩.
   - Pinecone 벡터 데이터베이스와의 연동을 통해 고성능 시맨틱(Semantic) 검색을 수행하되, 외부 API 장애 혹은 오프라인 로컬 테스트 환경을 고려하여 자체 "오프라인 폴백(Offline Fallback)" 메커니즘을 설계함으로써 서비스 연속성과 99.9% 수준의 높은 가용성을 보장.
3. RAG(Retrieval-Augmented Generation) & Gemini 2.0-flash / 1.5-flash Multi-Model Generation Engine
   - 컨텍스트(Context)와 질문(Prompt)을 동적으로 프레이밍하는 RAG 구조의 AI 답변 생성 엔진 설계.
   - 초고속 응답 속도를 자랑하는 최신 gemini-2.0-flash 모델을 기본 엔진으로 채택하고, API 할당량 제한이나 서버 불안정 상황 발생 시 gemini-1.5-flash 모델로 Graceful Degradation(자동 폴백)을 지원하여 끊김 없는 사용자 인텔리전스 경험 제공.
4. JWT Stateless Authentication & End-to-End Security Middleware
   - python-jose 및 bcrypt 암호화 라이브러리를 결합하여 패스워드를 안전하게 해싱하여 Supabase DB에 저장하고, 무상태성(Stateless)을 갖춘 JWT 기반 인증 메커니즘 구축.
   - app/api/deps.py에 중앙 집중식 의존성 주입(Dependency Injection) 설계를 적용하여, API Gateway 역할의 Middleware를 통과한 인가된 유저만이 AI 검색 및 답변 생성 등 주요 자원에 접근할 수 있도록 보안 정책 강제.
